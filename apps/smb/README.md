Super Mario Bros NES emulator for Vega OS Fire TV Sticks (FYAISA hub app).

- Runs in a WebView using jsnes
- Downloads the SMB ROM from an external source on first launch (no ROM bundled, legally clean)
- TV remote mapping: D-Pad, Menu=Start, Back=Select, FF=A, Play/Pause=B
- Targets armv7/aarch64/x86_64 and min Vega OS 1.2
